# User Stories Backlog

User stories derived from product modules, with acceptance criteria. Stories inform requirements traceability matrices and use-case coverage.

## Personas

- Administrator
- Office Worker
- Doorman
- Tenant
- Student Consult Organizer

## Modules

- Administration and Office
- Doorman Operations
- Tenant Forum
- Tenant Chat
- Cross-cutting (platform)

## Story format

Each story follows:

- **As a** `<role>`
- **I want** `<capability>`
- **So that** `<outcome>`
- **Acceptance Criteria**
