# User Stories Backlog

This directory contains initial user stories derived from the Dormitory Manager project overview.

## Personas

- Administrator
- Office Worker
- Doorman
- Tenant
- Student Consult Organizer

## Modules

- Administration and Office
- Doorman Operations
- Tenant Forum
- Tenant Chat

## Story Format

Each story follows:

- **As a** `<role>`
- **I want** `<capability>`
- **So that** `<outcome>`
- **Acceptance Criteria**
