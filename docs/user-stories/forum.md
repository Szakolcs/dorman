# Tenant Forum User Stories

## FM-001 News Feed Consumption

- **As a** tenant
- **I want** to view dorm news and updates in a forum feed
- **So that** I stay informed about dorm life

### Acceptance Criteria

- Feed shows official news and community announcements.
- Feed supports sorting by newest and pinned priority.
- News details page supports comments and reactions.

## FM-002 Community Activity Posting

- **As a** tenant
- **I want** to advertise an activity in the forum
- **So that** I can invite others to join

### Acceptance Criteria

- Post includes title, description, time, and location.
- Tenant can edit or archive their own activity post.
- Interested tenants can mark attendance intent.

## FM-003 Student Consult Event Management

- **As a** student consult organizer
- **I want** to create and manage official events
- **So that** student programs are visible and coordinated

### Acceptance Criteria

- Event supports registration cap and deadline.
- Organizer dashboard shows attendee intent counts.
- Event updates notify interested tenants.

## FM-004 Poll Creation and Voting

- **As a** student consult organizer
- **I want** to create polls for tenant decisions
- **So that** the community can vote transparently

### Acceptance Criteria

- Poll supports single and multiple choice.
- Voting is limited to eligible tenant accounts.
- Results visibility can be set to live or post-close.

## FM-005 Reactions and Comments

- **As a** tenant
- **I want** to like and comment on posts/events
- **So that** I can engage with the dorm community

### Acceptance Criteria

- Users can add/remove likes on posts and comments.
- Comment threads support edit/delete by author.
- Basic moderation controls exist for staff roles.
