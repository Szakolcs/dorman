# Chat Features

## Flat Room Automation

- Auto-created room per flat
- Automatic membership synchronization from assignments

## Direct Messaging

- One-to-one chat threads
- Conversation search and unread badges

## Group Chats

- User-created activity/friend groups
- Membership and role controls inside groups

## Profile Features

- Avatar upload
- Nickname customization (default from full name)
- Bio editing

## Messaging UX

- Near real-time delivery experience
- Retry states for transient failures
- Read/unread state indicators

## Chat HTML Surface

- Browser workspace under `/chat/view`
- Room timeline pages with send form and membership actions
- Profile edit page for nickname/avatar/bio
