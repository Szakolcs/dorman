# Platform Features

Cross-cutting capabilities shared by all product modules. Requirements: [platform.md](../requirements/platform.md). Specification and integration matrix: [platform.md](../specifications/platform.md).

## Authentication and Role Permissions

- Role-based route and action protection
- Permission checks across API and service layers

## Audit and Traceability

- Critical action audit logs
- Searchable event history by actor and module

## Notification System

- Event-driven in-app notifications
- User preference model for non-critical notifications

## Health and Monitoring

- Service health endpoint
- Dependency health reporting (API/database)
