# Doorman Features

## Package Intake and Pickup

- Intake form with tenant mapping
- Package state machine (received, notified, picked up)
- Pickup confirmation and handover logging

## Tenant Notification Tools

- In-app notifications triggered from package records
- Delivery status and retry support

## Guest Access Desk

- Guest lookup by tenant/guest
- Check-in and check-out logging
- Denial path for out opf visit time entries

## QR Access Validation

- QR code verification for entry decisions
- Access event logs with timestamps

## Accessories and Key Lending

- Checkout/return workflows
- Overdue detection and reminder hooks
- Availability dashboard for shared equipment
