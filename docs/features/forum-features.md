# Forum Features

## Unified Feed

- Aggregated stream for official and community content
- Sorting and pinning for important updates

## Community Activities and Events

- Activity/event posts with time and location metadata
- Attendance intent toggles for participants
- Organizer updates with participant visibility

## Polling

- Poll creation with configurable answer types
- Vote eligibility enforcement
- Result visibility modes (live vs post-close)

## Engagement

- Likes/reactions on posts
- Comment threads with edit/delete ownership rules
- Staff moderation controls for community safety

## Forum HTML Surface

- Browser-first feed workspace under `/forum/view`
- Forms for post creation, commenting, poll voting, and event intent
