## Why this folder exists

Product specs under **`docs/requirements`** and **`docs/specifications`** answer **why** features exist. **`docs/dev`** answers **how to run and change code**. **`docs/agent`** answers **what development was aided by Agents**, **what prompts were given**, and how **it solved the isseus**.
