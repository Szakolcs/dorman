## Why this folder exists

- **`docs/requirements`** and **`docs/specifications`** answer **what** the product must do.
- **`docs/dev`** answers **how to run and change code** (when populated).
- **`docs/agent`** records **how agent-assisted development proceeded**: prompts, outcomes, and issues resolved during iteration.
